# Industry-Oriented Machine Learning System for Fraud Detection

Complete RISE Internship project package.

## Everything included
- Self-contained demo transaction dataset
- Python training code
- Jupyter Notebook
- Trained Random Forest/selected best model
- Imputer + scaler
- Model comparison CSV
- Real generated graphs
- Screenshots
- Project report
- Streamlit app
- GitHub upload instructions
- Requirements

## Run on Windows
```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src/train_model.py
jupyter notebook notebooks/Fraud_Detection_ML.ipynb
```

The included dataset is synthetic so the ZIP is completely self-contained. If your internship specifically requires the ULB/Worldline credit-card dataset, replace the CSV with that approved dataset and adapt the feature columns before final submission.
